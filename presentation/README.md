# Aether’s Trial — Windborne presentation

- **Aethers_Trial_Windborne.pptx** — 11 editable slides with speaker notes. Text, icons, diagrams and the schematic map are native PowerPoint objects; gameplay screenshots are embedded images.
- **Aethers_Trial_Windborne.pdf** — matching PDF for easy viewing and sharing.
- **STORY.md** — the story, cast, three-act structure, gameplay mapping, a short spoken pitch and explicit current/future scope.
- **rendered/** — slide images used for visual review.
- **assets/** — gameplay screenshots used in the deck.
- **build-presentation.cjs** — reproducible pptxgenjs source. Run from a Node environment with `pptxgenjs` available. It prefers the final screenshots in `../shots/` and copies the selected images into `assets/`.

The presentation describes a local, unofficial fan-made prototype inspired by Genshin Impact. It separates implemented gameplay and journal/dialogue text from future memory quests and richer art. Full asset and reference provenance is in [`../CREDITS.md`](../CREDITS.md). Speaker notes include presentation guidance and credits.

The final deck includes the 30-second guardian fight and memory-loss opening, movement and enemy upgrades, and a dedicated technology slide. It contains original gameplay screenshots, actual intro frames, and speaker notes.
